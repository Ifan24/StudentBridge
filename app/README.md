# StudentBridge App Workspace

Use this folder for app development or prototype planning. In a Next.js App Router project, this folder can later become the actual route tree.

## Possible app areas

- onboarding for new international students
- networking event directory
- job board finding
- student forum for posts, replies and peer Q&A
- verified employer sessions
- volunteering and industry experience listings
- support-service discovery
- premium subscription and AI usage limits
- AI onboarding, recommendations and networking helper
- safety, verification and privacy controls

## Early screen ideas

- Jobs and work opportunities
- Student forum
- Career networking
- Support services
- AI assistant
- Premium subscription
- Profile and privacy settings
